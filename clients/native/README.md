# proteus-native

Экспериментальный нативный клиент на GPUI (`gpui-kit`). Работает с тем же
HTTP/SSE app-server, что и `clients/app`, через DTO из
`proteus-contracts::app_protocol`; основной клиент остаётся в `clients/app`.

Пакет исключён из root workspace и собирается на Rust 1.95
(`rust-toolchain.toml`):

```bash
cd clients/native
cargo build --release
./target/release/proteus-native [workspace] [--config <profile|path>]
./target/release/proteus-native [workspace] --origin <url> --token <token>
```

Без `--origin` клиент сам запускает `proteus server http` для workspace
(по умолчанию — текущий каталог). Бинарь сервера берётся из `PROTEUS_BIN`,
затем рядом с клиентом, затем из `PATH`; профиль по умолчанию — из
настроек desktop-приложения. Сервер получает `PR_SET_PDEATHSIG` и
завершается вместе с клиентом.

Устройство:

- `transcript` — headless модель ленты: snapshot и live fold runtime
  событий по правилам `app_server/turn_progress.rs`, без GPUI;
- `tool_display` — заголовки инструментов, разбор patch и плана;
- `settings` — headless черновик и каталог страниц настроек агента поверх
  `/config/builder` и `/config/history`: страница на каждый слот (Model,
  Workflow, Context, Context Providers, Compactor, Tools, Tool Exposure,
  Policy, Hooks; неизвестные слоты добавляются по порядку), Plugins и
  History с откатом; поля строятся по `config_schema` модулей, сохранение
  отправляет только изменённые разделы;
- `preferences` — настройки самого клиента (тема, анимации, отправка
  сообщения, включённые расширения, места и закрепление значков,
  раскладка вкладок) в `~/.config/dev.proteus.native/preferences.json`;
- `tabs` — headless раскладка вкладок: одна или две области, вкладки
  чатов `chat:<папка сессии>` и документов `<расширение>:<аргумент>`,
  вкладка предпросмотра, выбор активного чата, правила открытия, переноса
  и закрытия;
- `files` — headless DTO `/workspace/*` и модель дерева: ленивые листинги,
  отметки git, локальный фильтр по открытым папкам и дерево совпадений
  поиска `/workspace/search` по всему проекту (с учётом `.gitignore`);
  папка из результатов открывается в обычном дереве;
- `api`, `connection` — блокирующие HTTP-запросы и SSE-поток в отдельных
  потоках;
- `ui` — окно: левая боковая панель (сессии или вид расширения), вкладки
  чатов и документов в одной или двух областях, экран настроек (блоки
  «Агент» и «Клиент»); `ui/chat` — самостоятельный вид одной сессии
  (`Chat`): поток событий, лента, подтверждения, вопросы, очередь и поле
  ввода; `ui/chats.rs` — открытые чаты окна, активный чат и список
  сессий; `ui/motion.rs` — общие
  анимации: появление страниц, раскрытие по высоте (детали инструментов,
  «Дополнительно» и параметры в настройках), плавные числа в значках;
  уровень анимаций из настроек учитывается везде, ответ модели при
  стриминге проявляется по словам,
  `ui/drag.rs` — общий вид перетаскивания.

Чатов может быть открыто несколько, каждый — отдельная вкладка со своим
потоком событий; закрытие вкладки останавливает поток. Клик по сессии в
списке показывает её чат во вкладке предпросмотра (или переключает на уже
открытую), двойной клик или отправка сообщения оставляют вкладку; новая
сессия открывается обычной вкладкой. Закрыть можно любую вкладку, после
последней остаётся пустая область с кнопкой «Новая сессия». Раскладка
вместе с чатами восстанавливается при запуске, вкладки удалённых сессий
закрываются. Активный чат — показанный в области с фокусом, иначе
последний такой; к нему относятся заголовок окна, выделение в списке,
настройки агента, значки расширений и `Host`.

Расширения клиента (`ui/extensions`) описываются `Manifest` и получают
доступ к окну только через `Host` (чтение сессии активного чата и
активной вкладки, API, события `SessionOpened` — сменился активный чат —
и `RunSettled`, открытие документов во вкладках).
Расширение может дать значок (под полем ввода или в панели вкладок), вид
левой боковой панели и вкладки документов. Встроенные: контекст (кольцо
заполнения), план, лимиты модели (`/model/quota`), сессия, агент и файлы:
значок с числом изменений, дерево и список изменений git слева, файлы во
вкладках с просмотром и diff против HEAD. Одиночный клик открывает файл во
вкладке предпросмотра (курсив), которую заменит следующий файл; двойной
клик, `Enter` или перенос вкладки оставляют её. Дерево следует за активной
вкладкой. Подробности значков — во всплывающей подсказке.

Расширения включаются в настройках «Клиент → Расширения». Значки
перетаскиваются между полосами, правый клик меняет место значка, скрывает
или закрепляет его. Вкладки перетаскиваются между областями, на правый
край — чтобы разделить область; ширина областей меняется разделителем
(двойной клик — поровну). При перетаскивании под курсором едет копия
элемента, а место вставки отмечается линией.

Клавиши: `Ctrl+,` — настройки, `Ctrl+Shift+E` — дерево файлов или
сессии слева, `Ctrl+N` — новая сессия, `Ctrl+Tab`/`Ctrl+Shift+Tab` —
вкладки активной области, `Alt+↑`/`Alt+↓` — соседняя страница настроек. В
дереве файлов: стрелки, `Home`/`End`, `Enter` — открыть файл во вкладке,
`Space` — предпросмотр или свернуть папку, `/` или `Ctrl+F` — поиск по проекту.
