# Сравнение DeepSeek после исключения сетевых сбоев и сработавших лимитов

Использованы сохранённые прогоны DeepSeek V4.1 Flash с effort high. Новых запросов модели для этого отчёта — 0.

Из 35 первых попыток длинной серии исключены 14 запусков с ошибкой model transport/CLI, сработавшим пределом ответа или общим deadline. Оставшиеся 21 запуск содержат 19 полных проходов, однако наборы задач по сборкам различаются. Их отдельные статусы сохранены в JSON.

Для общей таблицы взяты одинаковые задачи для всех пяти сборок. Это шесть коротких задач и три длинные — db-wal-recovery, write-compressor, go-review. Каждый запуск — первая попытка. Все пять сборок прошли 9 из 9. Фильтр применялся к техническим причинам завершения, результат grader в условие отбора не входит.

Input уже включает cached input. Output включает reasoning. Usage native OpenCode также включает служебные обращения, полное число его model requests неизвестно. Сумма времени складывает длительности девяти запусков, проходивших параллельно с другими запусками. Она зависит от нагрузки провайдера.

У Proteus Pi по сравнению с Pi входных токенов на 0,5% меньше, выходных на 16,8% меньше, сумма времени на 18,6% меньше. У Proteus OpenCode по сравнению с OpenCode входных токенов на 36,4% меньше, выходных на 13,0% меньше, сумма времени на 14,4% меньше.

После фильтра в общей таблице остаётся решаемая всеми часть корпуса. Различия в качестве на более тяжёлых задачах требуют исходной таблицы и отдельных причин отказа. Расход описывает сохранённые версии runtime. Служебные вызовы, ошибки tools и recovery модели внутри этих траекторий входят в измерения. Денежная стоимость из токенов здесь не вычислялась.

Контрольные повторы Go, повторные запуски после исправлений, cold continuation и остановленные пользователем прогоны в таблицу не входят. Ошибка импортирующего загрузчика sampler не влияет на общий набор, поскольку sampler исключён.

[Исходная длинная серия](2026-11-11-deepseek-long.md) и [исходный короткий набор](2026-11-11-harness-fidelity.md) содержат версии runtime, условия и ограничения. JSON этого отчёта сохраняет источник каждой выбранной строки и причины удаления остальных.
