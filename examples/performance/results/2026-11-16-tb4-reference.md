Ниже внешние результаты; собственного score Proteus здесь нет.
Текущий native Go catalog именует выбранный slug `deepseek-v4.1-flash`
как **DeepSeek V4.1 Flash 1017**, release/last_updated `2026-10-17`.

AA пересчитывает стоимость с актуальными typical cache-hit measurements.
Это не исторический счёт за все 198 попыток. Числа восстановлены из публичного
SSR `weightedCostPerTask` (high 0.07829744053109795, max 0.08800788931797693),
веса TB4 0.1 и 66 задач. Не умножать их на три и не выдавать за bill авторов.
Aider определяет стоимость на момент проведения прогона (3 октября 2025);
его результат относится к другой модели и допускает исправление после тестов.

В TB4.0 submission среднее время попытки **5030,4 с /83,8 минуты**.
Деление $184,89 на 330 даёт $0,5603 за попытку, на 132 — $1,4007 за успех
с распределением расходов всей серии, на пять — $36,98 за эквивалент прохода.
Два харнеса ×66×1 при таком же среднем стоили бы $73,96; это прогноз,
не измеренный расход Proteus или цена по Go. По среднему AA/high — $103,35.

Запись того же запуска на **TB4.1** после regrade имеет 38,48%, а не 40,0%.
Начальный SSR `tbench.ai` отдаёт 4.1 независимо от query. Для 4.0 проверен
публичный leaderboard API с `name=4-0-0`. Его row содержит 8 187 123 046
обработанных токенов, output 164 097 378, cached input 7 598 818 520.
Нули token fields в GitHub submission являются отсутствующими данными,
а не нулевым расходом. Снимки row и submission сохранены локально в
`target/performance/tb4-pilot/references/`.

Из этого следуют ограничения подготовленного пилота:

- Семь задач, отобранных по ресурсам, не дают точный score на полном TB4.
  Для 3/7 условный 95% интервал Уилсона — примерно 16–75%; отбор не случаен.
- Бюджет 1200 с вместо upstream 28800 существенно меняет условия.
  Такой пилот проверяет стенд, но не воспроизводит headline score.
- Сравнение харнесов требует одинаковых задач, verifier, effort и бюджета.
  Недостаточно взять общий score чужого полного прогона вместо своего A/B.
- Сентябрьские 31,2% относятся к раннему V4.1, а не выбранному 1017.
- Расход подписки Go следует сверять с её usage; долларовые оценки каталога
  и опубликованные чужие расходы не доказывают фактическое списание Go.

На этом этапе штатные oracle controls запускаются локально без модели.
Платные прогоны отложены по запросу владельца до представления этих цифр.
