# Общая семантика сессии

Чистые проверки canonical journal и проекции истории, usage и контекста модели.
Библиотеку используют Core и внешние модули хранения через одинаковые DTO из
`proteus-contracts::storage::journal`. Формат журнала, файлы, SQLite, writer lease,
транспорт и алгоритмы конкретного провайдера сюда не входят.

`JournalValidationState` проверяет последовательность и attribution фактов,
идентичность частей истории, подтверждённые tool results и жизненный цикл хода.
`HistoryCapture` сохраняет порядок результатов при параллельном выполнении и
подтверждении checkpoint. Проекции usage и model context не превращают локальные
оценки в фактические расходы модели.

Canonical journal DTO сохраняют schema 21. Их сериализация для process storage
не определяет физическую кодировку backend: JSONL и SQLite используют один
контракт с независимыми способами durable commit.
